# RoboBilliard Vision

Прототип автоматического судейства для робо-бильярда. Верхняя камера наблюдает за полем, OpenCV ищет белые и оранжевые мячи, а табло начисляет очки за предполагаемые попадания в четыре угловые лунки. Судья управляет таймером и может скорректировать счёт вручную.

[Спецификация автосчёта](docs/specification.md) · [Протокол проверки на видео](docs/video-validation.md)

## Установка

Перейдите в папку `vision`. Проверено с Python 3.12. Для определения метки робота нужна сборка OpenCV с ArUco.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск табло

```sh
python scoreboard.py --camera 0 --config vision_config.json
```

На компьютере судьи откройте `http://127.0.0.1:8765/judge` и нажмите «Старт». Для проектора откройте адрес, напечатанный в терминале, с устройства в той же локальной сети. Кнопки табло позволяют поставить таймер на паузу, сбросить раунд, выбрать дополнительные 30 секунд и поправить очки.

Для демонстрации с сохранённой записью запустите `python scoreboard.py --video путь/к/записи.avi`. Табло проигрывает файл циклически. По умолчанию табло и скрипт проверки используют калибровку записи от 28 ноября 2026 года.

Для калибровки новой камеры запустите `python robobilliards_vision_test_v02.py`. Нажмите `C` и укажите четыре угла поля по часовой стрелке. Скрипт сохраняет калибровку в `vision_config.json` после четвёртого щелчка. `S` сохраняет снимок, `V` включает или останавливает запись, `Q` закрывает программу.

Шаблоны для печати ArUco ID 0: [A4](RoboBilliard_ArUco_ID0_A4.pdf) и [компактный A4](RoboBilliard_ArUco_ID0_compact_A4.pdf).

## Проверка видео

```sh
python replay_scoring.py --config tests/auditorium_2026-11-28/vision_config.json путь/к/записям/*.avi > replay-results.json
```

Отчёт JSON содержит число прочитанных кадров, число кадров с ArUco ID 0, координаты лунок, итоговый счёт и список начислений. Для повторения прогона нужны исходные AVI из локального архива съёмки.
